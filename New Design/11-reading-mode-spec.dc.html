Screen by screen
Pulse
Data leads on four metric cells. Editorial leads on the focus sentence and keeps the same four as a strip under the chart.
Timeline
Same table, same calendar. Editorial adds an hour-by-hour sentence above each group and a paragraph reading the year.
Activity
Data keeps the hourly columns as the hero. Editorial opens with the break pattern in words, then the same chart annotated.
Power
Editorial states the trade-off — highest draw versus highest cost — then proves it with the ranked table.
Tools
Identical in both modes. A timer and a set of targets don't benefit from narration.
Settings
Identical, plus the Reading mode row above. It is the one screen that must look the same in either state.
